# Carcará / myLinux — Release 2.0.2

**Tag:** `v2.0.2` (when cut)  
**Date:** 2026-11-17  
**Package:** `carcara-electron` `2.0.2` → `carcara_2.0.2_amd64.deb` + AppImage (via GitHub Actions on Release publish)

## Highlights

- **Electron as desktop user** — GUI no longer runs as root; fixes X11/Wayland auth, D-Bus, and GLES failures on native Linux (`sudo ./start.sh --electron` on yavin).
- **Privilege via helper only** — apt/install/fix/clean stay on allowlisted `run-helper` + `pkexec` (same model as packaged `.deb`).
- **Safer entry** — `./start.sh --electron` without sudo; accidental `sudo` re-execs as `SUDO_USER` with session env.

## What’s new since 2.0.1

### Entry / privilege

| Change | Detail |
|--------|--------|
| `start.sh` | Drop elevate-for-electron; `drop_root_for_electron` restores `DISPLAY` / `XAUTHORITY` / `WAYLAND_DISPLAY` / `DBUS_SESSION_BUS_ADDRESS` / `XDG_RUNTIME_DIR` |
| Bare root | Error if UID 0 without `SUDO_USER` — use `./start.sh --electron` |
| `CARCARA_REQUIRE_ROOT` | Default **`0`** (Zod + `.env.example`); `1` is legacy opt-in only |
| Docs / Sobre | README, playbook, idea, locales entry string → no-sudo Electron |

## Install

```bash
# From the GitHub Release asset (after CI attaches packages):
sudo apt install ./carcara_2.0.2_amd64.deb
carcara   # elevates via pkexec when needed

# From a clone (dev) — no sudo for the UI:
./start.sh --electron
```

Build locally: `cd carcara-electron && bun run pack:linux`.
