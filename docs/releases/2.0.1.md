# Carcará / myLinux — Release 2.0.1

**Tag:** `v2.0.1`  
**Date:** 2026-11-17  
**Package:** `carcara-electron` `2.0.1` → `carcara_2.0.1_amd64.deb` (via GitHub Actions on Release publish)

## Highlights

- **Richer software catalog (Waves A–C)** — thin installers on apt → Flatpak/Flathub → Snap, wired in 1.x menus and 2.0 Software tiles.
- **Packaging** — `.deb` via `electron-builder` + GHA `release-deb.yml`; packaged runtime uses Node `run-helper-node` (no Bun on target).
- **i18n** — nested `locales/{pt,en}.json`, rail **PT|EN**, `{version}` in window title / ready log.
- **Dotfiles + license** — Dotfiles rail/menus; 2.0 license gate (1.x parity).
- **Smoke harness** — `bun run smoke:software` (UI ↔ helper ↔ scripts + ping + pkexec probe).

## What’s new since 2.0.0 usable alpha

### Catalog

| Wave | Additions |
|------|-----------|
| **A** | Firefox, Brave, WhatsApp, Cursor, Termius, Postman, Anki, Notion, Thunderbird, Steam, OBS; `install_deb_url` |
| **B** | Heroic, Lutris, Vivaldi, Opera, Zen (GitHub AppImage), Audacity, Navidrome; 1.x folders `games/` / `browsers/` / `music/` |

Policy: **apt → Flatpak → Snap**. Docker Desktop skipped (Engine via `docker.sh` is enough).

### Product / UX

- Sistema: update / fix / clean / **sync-time**
- Software pagination (6/page), category search, backend badges
- Brand version pill ← `package.json`
- Hardened `dependences.sh` (apt-family, Flathub, NI-safe notify)

### Tooling

- `install_deb_url` / `install_appimage_url` backends
- Skills: `bash-scripting`, `debian-linux-triage` (+ existing shellcheck / ui-ux-pro-max)
- Smoke: `cd carcara-electron && bun run smoke:software`

## Install

```bash
# From the GitHub Release asset (after CI attaches the .deb):
sudo apt install ./carcara_2.0.1_amd64.deb
carcara   # elevates via pkexec when not root

# From a clone (dev):
sudo ./start.sh --electron
```

Build locally: `cd carcara-electron && bun run pack:deb`.

## Known limitations

- Baseline live smoke (`--live-core`) validated on owner machine; broader catalog / **pkexec** still optional (WSL often lacks `policykit-1`).
- **AppImage** packaging landed after tag `v2.0.1` (use `bun run pack:appimage` / next Release CI `pack:linux` to attach).
