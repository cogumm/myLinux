# `.cursor/` — Cursor adapter

This folder is **Cursor-specific**.

- `rules/*.mdc` — always-on / scoped rules loaded by Cursor
- Mirror for Claude Code: `.claude/rules/*.md` (keep in sync)
- Canonical product docs live in **`.agents/`** (`idea/`, `playbook/`)

When changing project guidance, edit `.agents/` first, then update rule pointers if paths change. Keep `.cursor/rules` and `.claude/rules` aligned.
