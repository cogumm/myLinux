# i18n (pt / en)

Shared UI strings for Carcará **1.x** and **2.0**.

## Source of truth

| Path | Role |
|------|------|
| `locales/pt.json` | Portuguese (default) — **nested** groups (`menu`, `tile`, `view`, …) |
| `locales/en.json` | English — **same nested shape** as `pt.json` |
| `carcara/app/config/i18n.sh` | Bash `t KEY` (python3 flattens nested JSON) |
| `carcara-electron/src/renderer/lib/flatten-locale.ts` | Shared flatten helper |
| `carcara-electron/src/renderer/lib/i18n.ts` | Renderer `t()` / lang + `localStorage` |
| `carcara-electron/src/native-i18n.ts` | Main-process `nativeT()` |

Call sites keep **dotted** keys after flatten: `t("menu.choose")`, `t("tile.update.title")`, `t("sobre.fact.product.label")`.

## Placeholders (`{version}`)

| Key | Template | Filled by |
|-----|----------|-----------|
| `window.title` | `Carcará {version}` | Main: `nativeT(..., { version: app.getVersion() })` |
| `ready.log` | `$ Carcará {version} pronto.|ready.` | Renderer: `t(..., { version: APP_VERSION })` |

- Source of truth: `carcara-electron/package.json` `"version"` (`lib/version.ts` / Electron `app.getVersion()`).
- API: `t(key, vars?)` and `nativeT(key, vars?)` replace `{name}` tokens.
- Do **not** hardcode `2.0` / `2.0.1` in locale strings.

## Selecting language

```bash
export CARCARA_LANG=en          # 1.x menus (Zenity)
# or in carcara-electron/.env:
CARCARA_LANG=en
```

- Explicit `CARCARA_LANG` wins (`pt` or `en*`); Zod default `pt`.
- If unset, 1.x falls back to `LANG` / `LC_MESSAGES` (`en*` → English, else Portuguese).
- **2.0 rail PT | EN:** overrides via `localStorage` (`carcara.lang`) and remounts the shell; clear storage → env default again.
- Native Electron menu labels follow env until process restart.

## Patterns

- **1.x Zenity:** hidden `id` column + `--print-column=1`; `case` on stable IDs; labels via `$(t …)`.
- **2.0:** resolve lang before license gate; remount on lang switch; views use `getMeta()` / `t()` at render time.
- Product names (Git, Discord, VLC, Carcará, Ko-fi, …) stay untranslated.
- Technical tile hints (`apt → Flatpak → Snap`) may stay English.
- Brand marks (`cogumm.net`) not localized; version comes from `package.json` (`APP_VERSION` / `app.getVersion()`). Locale strings may use `{version}` (e.g. `window.title`, `ready.log`) — interpolate via `t(key, { version })` / `nativeT(key, { version })`.
- Hosts running 1.x `t` need **python3** (nested flatten).

## Add a string

1. Add the nested field to **both** `locales/pt.json` and `locales/en.json` (identical path).
2. Use the dotted key: `t "menu.choose"` (Bash) or `t("menu.choose")` (TS).
3. Keep pt/en key parity (CI/manual: flatten both and diff key sets).
